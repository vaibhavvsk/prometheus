# Rebuild — UBI9 Image Build Approach

## Overview

This repository extends the upstream Prometheus build system with a thin SPS
overlay that adds an IBM Cloud–targeted Docker build pipeline on top of the
unmodified upstream Makefile.

---

## File Renaming Convention

| File | Role |
|---|---|
| `Makefile.org` | The **original upstream** Prometheus `Makefile`, renamed verbatim. It is never edited — all upstream changes are merged into this file. |
| `Makefile` | The **SPS entry-point** Makefile. It starts with `include Makefile.org` so every upstream target is inherited, then adds SPS-specific targets below. |

### Why rename instead of patch?

Keeping upstream content isolated in `Makefile.org` means:

- Upstream diffs apply cleanly with no conflicts against SPS additions.
- It is immediately obvious which lines are ours vs. upstream.
- Future upstream updates only touch `Makefile.org`.

---

## Makefile Structure

```
Makefile          ← SPS entry-point (our additions live here)
  └─ include Makefile.org    ← upstream Prometheus Makefile (unmodified)
       └─ include Makefile.common   ← upstream shared rules
```

The `Makefile` defines the following variable defaults (overridable on the
command line) and build targets:

| Variable | Default | Purpose |
|---|---|---|
| `DOCKER` | `docker` | Docker binary; override with `podman` if needed |
| `INFO` | `echo [INFO]` | Logging prefix for step start messages |
| `OK` | `echo [OK]` | Logging prefix for step success messages |
| `REGISTRY_NAMESPACE` | *(must be set)* | IBM Cloud Container Registry namespace |
| `REGISTRY_IMAGE` | *(must be set)* | Image repository name |
| `REGISTRY_IMAGE_TAG_SHORT` | *(must be set)* | Short tag (e.g. `3.13.0-ubi9`) |

## Added Dockerfile: `Dockerfile.ubi9`

A new multi-stage Dockerfile that produces a fully UBI9-based image — no
Debian or Alpine tooling is introduced at any stage.

### Stages

| Stage | Base image | Purpose |
|---|---|---|
| `builder` | `registry.access.redhat.com/ubi9/go-toolset:latest` | Compiles the Mantine UI (pnpm/Vite) and both Go binaries (`prometheus`, `promtool`) with `CGO_ENABLED=0` and the `builtinassets` tag |
| runtime | `registry.access.redhat.com/ubi9/ubi-minimal:latest` | Copies only the two compiled binaries and the default config; runs as UID 65534 (`nobody`) |

### Key build decisions

- **UBI9 Go toolset** ships Node.js 22, so no external NodeSource install is
  needed; only `dos2unix`, `gzip`, and `tar` are added via `dnf`.
- **`dos2unix`** is run over all `.sh` scripts before execution to handle
  Windows (`CRLF`) checkouts.
- **`builtinassets` tag** embeds the compiled web UI into the binary via
  `web/ui/embed.go`, generated by `scripts/compress_assets.sh`.
- **Static binary** (`CGO_ENABLED=0`, `-tags netgo`) — no glibc dependency at
  runtime; works on UBI9 Minimal.

## Build Targets

```
make docker-build   # Build the UBI9 image and tag it for IBM Cloud Container Registry
```

Planned additional targets (to be added to `Makefile`):

```
make docker-push     # Push the tagged image to us.icr.io
make docker-promote  # Promote image from dev to prod namespace
```

---

## Running the Build

```bash
make docker-build \
  REGISTRY_NAMESPACE=my-namespace \
  REGISTRY_IMAGE=prometheus \
  REGISTRY_IMAGE_TAG_SHORT=3.13.0-ubi9
```

Override the Docker binary to use Podman:

```bash
make docker-build DOCKER=podman ...
```

---

## Environment Variables — Export Before Building

```bash
# 1. Log in to IBM Cloud and the Container Registry
ibmcloud login --apikey <YOUR_API_KEY> -r us-south
ibmcloud cr login

# 2. Set required registry variables
export REGISTRY_NAMESPACE=my-namespace          # ICR namespace you own
export REGISTRY_IMAGE=prometheus                # repository name inside that namespace
export REGISTRY_IMAGE_TAG_SHORT=3.13.0-ubi9    # tag, e.g. <version>-ubi9

# 3. (Optional) Use Podman instead of Docker
export DOCKER=podman

# 4. Verify the resolved image reference before building
echo "us.icr.io/${REGISTRY_NAMESPACE}/${REGISTRY_IMAGE}:${REGISTRY_IMAGE_TAG_SHORT}"
# expected → us.icr.io/my-namespace/prometheus:3.13.0-ubi9

# 5. Build
make docker-build
```
